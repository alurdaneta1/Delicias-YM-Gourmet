# Delicias Y&M Gourmet

Aplicación para Android: consulta el menú, arma tu pedido y prepáralo para enviarlo por WhatsApp.

## Descargar la aplicación

**[Descargar Delicias Y&M para Android](https://github.com/alurdaneta1/Delicias-YM-Gourmet/releases/latest/download/Delicias-YM.apk)**

Versión publicada: **1.5**. Requiere Android 7 o posterior. Este archivo APK es para Android.

## Cómo instalar

1. Abre el enlace de descarga desde tu teléfono Android.
2. Cuando termine la descarga, abre el archivo **Delicias-YM.apk**.
3. Si Android lo solicita, permite instalar aplicaciones desde el navegador que utilizaste y confirma **Instalar**.
4. Abre **Delicias Y&M Gourmet** para preparar tu pedido.

Al tocar **Enviar pedido por WhatsApp**, el mensaje se abre en WhatsApp para que confirmes su envío. La aplicación vuelve al inicio con el carrito vacío.

## Qué incluye

- Menú, búsqueda, categorías, cantidades y total del pedido.
- Indicaciones opcionales para cada comida. Las bebidas no llevan indicaciones.
- Nombre obligatorio y dirección obligatoria únicamente para delivery.
- Pedido de WhatsApp con las indicaciones junto a cada comida y la dirección por separado.
